# Ley de Ohm interactiva · Interactive Ohm's law

## Resumen / Summary

**ES.** Actividad de navegador, en español e inglés, para estudiantes de Electrónica: predecir un valor, cambiar un solo dato, calcular y explicar qué cambió. El cálculo lo hace el código con la fórmula de Ohm; la IA no calcula nada dentro de la actividad. Incluye paquete SCORM 1.2.

**EN.** A browser activity, in Spanish and English, for Electronics students: predict a value, change a single input, calculate and explain what changed. The code does the calculation with Ohm's formula; the AI calculates nothing inside the activity. A SCORM 1.2 package is included.

Estado de la evidencia / Evidence status: 8 de 8 pruebas de código y 3 ejemplos calculados a mano coinciden. Ningún estudiante la ha probado todavía. / 8 of 8 code tests and 3 hand-calculated examples match. No student has tested it yet.
